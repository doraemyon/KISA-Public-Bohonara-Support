Title:
Termix Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "Termix Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o Termix project announces security update that addresses vulnerabilities in its products [2]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Path Traversal Vulnerability Occurring in Termix (CVE-2026-120322) [1][3]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-120322 / Termix / 2.9.2 or earlier / 26.10.0 or later
