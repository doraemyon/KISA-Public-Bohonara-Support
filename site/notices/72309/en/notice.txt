Title:
MongoDB Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "MongoDB Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update to the latest version.

Body:
□ Overview
o MongoDB has released security updates to address vulnerabilities occurring in its products [1][2]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Incorrect Behavior Order: Validate Before Canonicalize vulnerability in Node.js Driver(CVE-2026-126837) [1]~[3]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Versions / Fixed Version
CVE-2026-126837 / Node.js Driver / 3.3.3 and later 7.8.0 and earlier / 7.8.0 and later
※ Perform updates by checking the reference sites below [1][2]

[2] https://www.mongodb.com/resources/products/alerts
