Title:
NGINX Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "NGINX Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o F5 has released security updates addressing vulnerabilities in its NGINX products [1][2][3][4][5]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation instructions

□ Description
o Integer Underflow (Wrap or Wraparound) vulnerability in NGINX Plus and NGINX Open Source(CVE-2026-123007) [1][6]
o Use After Free vulnerability in NGINX Plus and NGINX Open Source(CVE-2026-123634) [2][7]
o Use After Free vulnerability in NGINX Plus and NGINX Open Source(CVE-2026-123633) [3][8]
o Use After Free vulnerability in NGINX Plus and NGINX Open Source(CVE-2026-121810) [4][9]
o Use After Free vulnerability in NGINX Plus and NGINX Open Source(CVE-2026-113425) [5][10]
