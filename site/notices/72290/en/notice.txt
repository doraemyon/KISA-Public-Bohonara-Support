Title:
SonicWall Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "SonicWall Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o SonicWall announces a security update that addresses vulnerabilities in its products [1]
o Users with affected versions are advised to update to the latest version as a workaround

□ Description
o Use of Single-factor Authentication vulnerability in SonicOS (CVE-2026-19868) [1] [2]

□ Affected Products and Solutions
Vulnerability / product name / Affected version / Resolved version
CVE-2026-19868 / SonicOS (Gen7) / 7.3.3-7015 or less / 7.3.4-7013 or later
CVE-2026-19868 / SonicOS (Gen8) / 8.2.2-8015 or less / 8.2.3-8015 or more
