Title:
Linux Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "Linux Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o The Linux Foundation has released security updates addressing vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Out-of-bounds Write vulnerability in the Linux Kernel NFS server (nfsd) (CVE-2026-99362) [1][2]
