Title:
Synology Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "Synology Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o Synology releases security updates that address vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Argument Injection vulnerability occurring in Synology DiskStation Manager (DSM)(CVE-2026-120382) [1][2]

□ Affected Products and Solutions
