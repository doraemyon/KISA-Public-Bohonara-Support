Title:
Security Update Advisory for Cyber Imagination Products

Summary:
Today, we will spread the contents of the KISA notice "Security Update Advisory for Cyber Imagination Products", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o Cyber Imagination has released a security update addressing a vulnerability in its product [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures
□ Description
o A vulnerability in D-Bridge allowing external access to internal administrator paths
□ Affected Products and Solutions
Product Name / Affected Version / Fixed Version
D-Bridge / 1.x / 2.5 or later
※ Perform the update by checking the reference site below [1]
□ Reference sites
[1] https://solution.cyber-i.com/main/support/center/notice.cmd
