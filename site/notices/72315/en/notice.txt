Title:
Oracle Product Security Update Advisory

Summary:
Today, we will spread the contents of the KISA notice "Oracle Product Security Update Advisory", and we advise those in charge of the affected versions to upgrade to the newest version.

Body:
□ Overview
o Oracle has released security updates to address vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation instructions
