Title:
Citrix Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update to the latest version.

Body:
□ Overview
o Citrix releases security updates to address vulnerabilities in its products [1]~[3]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-120868) [1][4]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107407) [1][5]
o Out-of-bounds Write Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107408) [1][6]
o Double Free Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107409) [1][7]
o Heap-based Buffer Overflow Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107410) [1][8]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107412) [1][9]
o Heap-based Buffer Overflow Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-107415) [1][10]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-120864) [1][11]
o Improper Authentication Vulnerability in NetScaler Console (CVE-2026-120869) [2][12]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-111334) [1][13]
o Improper Privilege Management Vulnerability in Secure Access Client for Windows (CVE-2026-118268) [3][14]
